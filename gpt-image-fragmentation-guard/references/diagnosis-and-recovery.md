# 碎图诊断与恢复

用这个文件处理已有坏图、连续编辑恶化或 API 输出疑似损坏的情况。不要根据外观猜测模型内部架构或水印机制。

## 症状矩阵

| 症状 | 先排查 | 高风险条件 | 首选动作 | 不要做 |
|---|---|---|---|---|
| 文件打不开、只有部分区域、像未画完 | 文件长度、格式、流式事件类型 | 保存 `partial_image`、传输截断、错误解码 | 重新取得 `completed`/最终事件并验证文件 | 用提示词修文件传输问题 |
| 蜂窝、棋盘格、细胞状或重复碎纹遍布整图 | 原始 PNG 与截图是否相同 | 密集微纹理、自然表面、雾/反光/粒子叠加、坏图递归编辑 | 降低细节密度和复合材质，从干净状态重生 | 宣称某条负面词能根治 |
| 单幅请求变成拼贴、分屏、角色表或信息图 | 最终/改写后提示是否含多场景或 sheet 语义 | “多个方案”“不同视角”“before/after”“reference sheet”等 | 拆成独立提示和独立工具调用；声明单一连续画面 | 在同一坏会话里无限追加 `no collage` |
| 主体粘连、漂浮碎片、背景断层 | 位置、尺度、透视、光源、材质边界是否定义 | 对象清单式提示、无主焦点、多重透明/反射材质 | 写空间关系图，统一主光和透视，减少复合材质 | 只追加“高清、细节丰富” |
| 额外肢体、左右错位、接触点断开 | 精确主体数、人物自身左右、承重脚、遮挡 | 多人重叠、复杂动作、低清姿势参考 | 错开轮廓，每人一个动作，写清接触和前后关系 | 粘贴几十项解剖负面词 |
| 局部编辑后全图漂移或出现接缝 | 是否从干净检查点开始、每轮是否只改一项 | 反复编辑同一坏图、一次改多处、参考职责冲突 | 回退检查点，缩小单次变化，重申不变量 | 继续在漂移结果上修修补补 |
| 旧图元素残留或同一会话越来越脏 | 新提示和新会话对照 | 长序列生成、连续引用先前坏图 | 用压缩后的完整提示在干净上下文重生 | 把“新会话”描述成必然有效的官方修复 |

## 快速对照测试

当故障来源不明时，用同一主题做三次最小化对照：

1. **文件对照**：确认正在看最终原始文件，而不是流式中间图、缩略图或高压缩截图。
2. **提示对照**：保留主题和主风格，只移除微细节、复合材质与多动作，生成一张标准尺寸图。
3. **状态对照**：在干净上下文用同一份压缩提示重新生成一次。

解释结果：

- 只有文件对照失败：优先修 API 或保存管线。
- 简化提示明显改善：复杂度和关系表达是主要可控因素。
- 新上下文明显改善：把上下文污染视为经验性线索，并保存最小复现。
- 三组仍出现相同全局碎纹：将其视为模型侧限制候选，停止无边界重试。


## 有限重试边界

- 对孤立随机错误，最多保持原提示重试一次。
- 对已定位的结构问题，最多进行一次针对性重写后重生。
- 对全局纹理噪声，做一次降复杂度重生；仍失败则报告限制。
- 用户要求继续探索时可以扩展，但每轮都要记录唯一变量和验收结果。
