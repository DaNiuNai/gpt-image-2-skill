# 防碎提示模板

模板是脚手架，不是必须填满的表单。只使用对当前请求有帮助的字段，保留用户原意。

## 单场景生成

```text
用途：<用途>
画面承诺：一张完整、连续的单场景画面；同一空间、同一时刻、同一摄影机视角。

场景：<地点>。前景为 <...>，中景为 <...>，背景为 <...>。
主体：画面中恰好有 <数量> 个主体：<逐一描述>。主要焦点是 <主体>。
空间关系：<主体 A> 位于 <位置>，比 <主体 B> <大/小/近/远>；<遮挡和接触关系>。
动作：<每个主体一个清晰动作>。
镜头：<景别、视角、透视、完整入镜范围>。
材质与细节：焦点区域 <高细节>；次要区域 <中等细节>；背景使用较大连续形状和受控细节密度。
光照：一个主要光源来自 <方向>，统一 <色温>，所有接触阴影与之匹配。
风格：<一个主媒介和相容风格>。

约束：所有主体共享同一地面、透视、光源和色温；轮廓连续，材质边界清晰。
排除：没有拼贴、分屏、多面板、随机边框、重复主体、漂浮碎片或画面接缝。
```

## 多人物或动物

```text
主体数量：恰好 <N> 个，分别为 A、B、C。
A：位于 <位置/景深>，<动作>，<哪只手/脚> 与 <对象> 接触。
B：位于 <位置/景深>，<动作>，轮廓与 A <不重叠/只在某处自然遮挡>。
C：<同上>。

身体关系：每个主体只有一颗头和一具连续身体；肢体从正确关节连接。
人物自身左/右：<明确说明>。
承重与接触：<哪只脚着地、重心、手抓握、物体支撑>。
取景：<全身/膝上/半身>，<脚/手> 完整入镜。
```

避免机械罗列一长串 `bad anatomy, extra limbs...`。几何关系比通用负面词更能说明用户真正要什么。

## 密集幻想或自然场景

```text
主要焦点：<唯一焦点>，清晰轮廓，承担最高细节。
次要元素：最多 <数量> 类，使用中等细节，不与焦点轮廓融合。
背景：使用大块、连续、安静的形状；只保留少量可读纹理。
材质边界：石头、植物、水、雾和发光元素保持清晰分区，不互相熔化。
光照：只有一个主光方向；发光物仅作局部辅光。
细节层级：细节集中于焦点，画面边缘和背景逐渐简化；不要全局微细节、重复纹样或过度锐化。
```

## 参考图生成或合成

```text
Image 1：底图，只提供场景、镜头和构图。
Image 2：主体参考，只提供身份、服装和外观。
Image 3：姿势参考，只提供身体姿态，不提供身份、服装或背景。

任务：把 Image 2 的主体放入 Image 1 的 <具体位置>，采用 Image 3 的姿势。
匹配：Image 1 的尺度、透视、光照方向、色温、遮挡和接触阴影。
保持：Image 1 的镜头、背景和未编辑对象；Image 2 的身份和比例。
不要复制：<每张参考中不应进入结果的内容>。
```

没有使用某类参考时删掉对应行。参考越多，职责越需要互斥和清楚。

## 单变量编辑

```text
只修改：<一个目标区域或属性>。
具体变化：<目标结果>。
必须保持：人物身份、身体比例、姿势、镜头、透视、构图、背景、光照、色温、未编辑对象和原始画质不变。
融合要求：边缘连续；材质、噪声尺度、光照和阴影与原图一致；没有贴片感或接缝。
不要添加：新人物、新物体、文字、标志、边框或未要求的装饰。
```

## 多个独立成品

先生成计划，不在一张画布里描述所有方案：

```text
需要 <N> 个独立成品。每个成品是一张单独图片文件，不是同一图片中的面板。

图片 1：<完整、独立提示>
图片 2：<完整、独立提示>
...

执行时每张图片使用一次独立图像生成调用；不要生成拼贴、联系表、网格或分屏。
```

## 全局碎纹后的干净重生

```text
根据原主题从头生成一张新图，不编辑或重绘那张已有碎纹的输出。
保留：<主题、主体、核心构图、主风格>。
简化：<删去的微细节、复合材质、次要对象或多余光源>。
结构：大而连续的形状，清晰轮廓分离，干净材质边界，受控细节密度，一个主光源。
排除：重复网格、蜂窝/细胞状碎纹、脏噪点、漂浮碎屑、画面接缝和过度锐化。
```

最后一行是症状特定排除项，不要继续扩展成通用负面词词典。
